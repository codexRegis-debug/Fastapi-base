To build an open-source alternative to Supabase/Firebase using Python 3.11.2, you will be assembling a system that handles Authentication (Firebase Auth / Supabase Auth), Automated CRUD Engine (Supabase Database Rest API), and infrastructure layers like Migrations, Rate Limiting, and Caching.
A quick architectural note before we begin: The library asyncio-redis is unmaintained and incompatible with modern Python 3.11+ event loops. Instead, use the official, native async client included in the main core Redis package: import redis.asyncio as redis. Additionally, fastapi-crudrouter is optimized for Pydantic v1. If you use Pydantic v2, ensure you use versions or forks compatible with it, or consider an alternative like fastcrud.

Phase 2: Configuration & Database Plumbing


Step 3: Base Settings Management

Use pydantic-settings to safely extract and validate system environment configurations:
python
# config.py
from pydantic_settings import BaseSettings, SettingsConfigDict

class Settings(BaseSettings):
    DATABASE_URL: str = "postgresql+asyncpg://postgres:pass@localhost:5432/supabase_db"
    REDIS_URL: str = "redis://localhost:6379/0"
    SECRET_KEY: str = "SUPER_SECRET_PROJECT_SIGNING_KEY"

    model_config = SettingsConfigDict(env_file=".env")

settings = Settings()

Step 4: Core Async Database & Session Factory

Configure the sqlalchemy[asyncio] engine utilizing asyncpg:
python
# database.py
from sqlalchemy.ext.asyncio import create_async_engine, async_sessionmaker, AsyncSession
from sqlalchemy.orm import DeclarativeBase
from collections.abc import AsyncGenerator
from .config import settings

engine = create_async_engine(settings.DATABASE_URL, echo=False)
AsyncSessionLocal = async_sessionmaker(engine, expire_on_commit=False, class_=AsyncSession)

class Base(DeclarativeBase):
    pass

async def get_async_session() -> AsyncGenerator[AsyncSession, None]:
    async with AsyncSessionLocal() as session:
        yield session
Use code with caution.

Step 4: Execute & Launch

1. Auto-generate the migrations pipeline: alembic revision --autogenerate -m "init".
2. Apply changes: alembic upgrade head.
3. Run the project application thread: uvicorn app:app --host 0.0.0.0 --port 8000 --reload.
